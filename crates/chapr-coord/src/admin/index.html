Administrator token

This coordinator keeps its admin token in its own data directory, beside the database — a directory the installer restricts to administrators and the service account. The setup wizard prints it; you can also read the admin-token file there.

The token does not depend on the connection auth mode, which is deliberate: it means a mistake made on the Settings tab can always be undone from this page.

Changing the connection auth mode

Run the new mode as the primary with the old one as a fallback, watch the endpoints arrive on the new mode, then remove the fallback. Both numbers below matter: a client that cannot authenticate under the new mode never appears as fallback use — it appears as a rejection.

Administrator token

Permanent by design — it is the way back in when the auth mode is wrong. It cannot be switched off, so rotation is how you answer "someone who has left may still have a copy". Rotating invalidates the current token immediately, including on this page.
